# CGAF-Net

Official implementation of **CGAF-Net: Bridging the Generalization Gap in Lung Cancer Histopathology via Cross-Gated Multi-Scale CNN Transformer Fusion**.

CGAF-Net is a CNN–Transformer fusion framework that combines ConvNeXt-Tiny and Swin-Tiny through cross-guidance gating and feature alignment to improve the generalization of lung cancer histopathology classification across datasets.

## Overview

This repository contains the implementation and experimental code used in our study for:

- Lung cancer histopathology image classification
- ConvNeXt-Tiny and Swin-Tiny feature extraction
- Cross-gated multi-scale feature fusion
- Cross-dataset evaluation
- Model training and evaluation
- Ablation studies

## Datasets

The experiments use publicly available:

- **LC25000**
- **LungHist700**

The datasets are not redistributed in this repository. Please obtain them from their original sources.
